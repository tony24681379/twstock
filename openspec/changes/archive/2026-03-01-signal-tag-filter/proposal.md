## Why

總表頁面（HomePage）已載入全部 ~2700 支股票的完整訊號資料（67 個訊號涵蓋籌碼、技術、基本面、極端事件、可轉債），但目前只能排序，無法按特定訊號組合篩選。使用者需要快速找出同時符合多個條件的股票（例如「多頭排列 + 大戶急買 + 營收加速成長」），目前只能逐一查看 tooltip，效率低落。

## What Changes

- 新增訊號標籤篩選 UI 組件，以可展開面板形式放在權重控制器下方
- 所有 67 個訊號按 6 個分類（籌碼、技術狀態、技術交叉、極端事件、基本面、可轉債）展示為可點擊標籤
- 點擊標籤加入篩選條件，再次點擊移除；使用 AND 邏輯（必須同時觸發所有已選訊號）
- 每個標籤顯示目前觸發該訊號的股票數量
- 表格即時篩選，顯示「符合條件: N / total 支股票」
- 純前端實作，不需修改後端 API（前端已載入全部股票資料）

## Capabilities

### New Capabilities

- `signal-tag-filter`: 總表頁面的訊號標籤篩選功能，包含訊號目錄定義、篩選 UI 組件、AND 邏輯篩選

### Modified Capabilities

（無需修改既有 spec，本功能為純新增的前端篩選層，不改變既有訊號計算或 API 行為）

## Impact

- **前端**：`dashboard/src/pages/HomePage.tsx`（整合篩選狀態）、新增 2 個檔案（SignalFilter 組件 + signalCatalog 常數）
- **後端**：無影響
- **API**：無影響
- **依賴**：無新增依賴，使用既有 Tailwind CSS + React hooks
