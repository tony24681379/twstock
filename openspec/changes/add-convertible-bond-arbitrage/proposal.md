## Why

台股可轉債（CB）具有天然的套利結構：當轉換價值高於 CB 市價時，買入 CB 並轉換為股票即可無風險獲利。目前系統僅追蹤普通股，缺少可轉債這個高勝率、低風險的投資維度。可轉債數量少（~150-200 檔）、計算邏輯明確、資料來源公開（TWSE/TPEX），適合作為系統的高優先級擴展。

## What Changes

- 新增可轉債資料爬蟲，從 TWSE/TPEX 官方 API + 公開資訊觀測站（MOPS）取得 CB 基本資訊與每日交易數據
- 新增 3 張資料庫表：`convertible_bond`（基本資訊）、`convertible_bond_daily`（每日交易）、`convertible_bond_signals`（套利訊號）
- 新增可轉債套利訊號系統（10 個訊號），核心邏輯：
  - **折價套利訊號**：轉換價值 > CB 市價（扣除交易成本後仍有利潤）
  - **低溢價率訊號**：溢價率 < 5% 且標的股趨勢向上
  - **催換機制訊號**：標的股價 > 轉換價 × 130%（公司可能強制贖回）
  - **CBAS 拆解機會**：選擇權價值被低估
  - **到期賣回保護**：接近賣回日且賣回價 > 市價（下檔保護）
  - **標的股基本面連動**：結合現有股票訊號系統評估標的股品質
- 新增 API 端點 `/api/convertible/*`，提供 CB 列表、詳情、套利機會排序
- **前端雙總表設計**：
  - **股票總表（原頁面）**：新增「CB 套利分數」欄位，有發行可轉債的標的股會顯示其 CB 套利評分（0-100），無 CB 的股票該欄為空。此分數作為一個指標融入現有排序/篩選體系
  - **可轉債總表（新頁面）**：獨立的 `/convertible` 頁面，以 CB 為主體的完整瀏覽表，顯示所有可轉債的套利資訊（溢價率、轉換價值、套利空間、訊號強度等），可依套利機會排序
- 新增 Excel 報表「可轉債套利」sheet
- 可轉債訊號在整體系統中列為**最高優先級**：Excel 報表第一個 sheet

## Capabilities

### New Capabilities
- `convertible-bond-data`: 可轉債資料爬取與儲存，涵蓋 CB 基本資訊（轉換價、到期日、發行量）和每日交易數據（價格、成交量、轉換價值、溢價率）
- `convertible-bond-arbitrage`: 可轉債套利訊號計算引擎，包含 10 個自動化訊號（折價套利、低溢價、催換、CBAS、到期保護等），產出套利機會評分與排序
- `convertible-bond-api`: 可轉債 REST API 端點，提供列表（含套利排序）、詳情、標的股對比、歷史趨勢
- `convertible-bond-dashboard`: 前端可轉債獨立總表頁面（`/convertible`），以 CB 為主體瀏覽所有可轉債套利機會，含溢價率、轉換價值、套利空間、訊號強度、標的股對比等完整資訊

### Modified Capabilities
- `chip-api`: 股票總表新增「CB 套利分數」欄位，有發行 CB 的標的股顯示其可轉債套利評分（0-100），融入現有排序/篩選體系；對應 API 回傳新增 `cb_arbitrage_score` 欄位
- `fundamental-info`: 股票詳情頁新增「關聯可轉債」區塊，顯示該股票對應的 CB 套利狀態

## Impact

### 資料庫
- 新增 3 張表（`convertible_bond`, `convertible_bond_daily`, `convertible_bond_signals`）
- 預估資料量：~150 檔 CB × 250 天 ≈ 37,500 筆日交易資料（<5MB），對 Neon 免費額度影響極小

### 爬蟲
- 新增資料來源：TWSE/TPEX 官方網站（免費公開資料）
- 爬取頻率：每日一次，~150 檔 CB 預估 <30 秒
- 不影響現有 Wantgoo 爬蟲

### API
- 新增 `/api/convertible` router（4-5 個端點）：列表、詳情、歷史、標的股對比
- 修改 `/api/stocks` 端點回傳新增 `cb_arbitrage_score` 欄位（有 CB 的標的股）

### 前端（雙總表）
- **股票總表（修改）**：新增「CB 套利分數」欄位，可依此排序/篩選
- **可轉債總表（新頁面）**：`/convertible` 路由，獨立的 CB 瀏覽頁
- 頂部導航新增「可轉債」入口

### Excel 報表
- 新增「可轉債套利」sheet（置於第一個 sheet）

### 依賴
- 無新增 Python 套件依賴（使用現有 httpx + BeautifulSoup/lxml 解析 TWSE 頁面）

### 套利核心公式
```
轉換張數 = 面額(100,000) ÷ 轉換價格
轉換價值 = 轉換張數 × 標的股收盤價 × 1,000
轉換溢價率(%) = (CB市價 - 轉換價值) ÷ 轉換價值 × 100
套利空間(%) = -溢價率 - 交易成本率(約0.6%)
```
