# 訊號定義與評分標準

本文件是所有訊號的 **唯一權威來源 (Single Source of Truth)**。
程式碼中的分數、條件、正規化公式必須與本文件一致。

> 修改規則：修改本文件需附上變更原因，並同步更新對應程式碼。

**最後更新**：2026-02-17

極端事件理論範圍：**-52 ~ +20**（計入互斥後的近似值）

### 1.4 正規化公式

```
理論範圍：-172 ~ +174（crossover + state + extreme）
normalized = ((raw_score + 172) / 346) * 100
clamp 到 [0, 100]
```

使用此公式的位置（必須全部一致）：
- `twstock/vectorized_signals.py` — `calculate_signal_strength()`
- `twstock/signal_updater.py` — `_update_signal_cache()`
- `api/services/stock_service.py` — `StockService.normalize_technical_score()`
- `twstock/stock_list_cache_updater.py` — 間接呼叫 `StockService.normalize_technical_score()`

## 四、可轉債套利訊號（10 個）

實作檔案：`api/services/convertible_signal_service.py`
更新流程：`twstock/convertible_bond_updater.py`

### 套利訊號（6 個，正分）

| # | 訊號名稱 | 分數 | 觸發條件 |
|---|---------|------|---------|
| 1 | 折價套利 | +20 | `conversion_value > cb_close × 1.006`（轉換價值扣交易成本後仍高於 CB 市價） |
| 2 | 低溢價率 | +15 | `premium_rate < 5%` 且 `underlying_strength > 50`（標的股技術面非弱勢） |
| 3 | 催換在即 | +15 | `underlying_close / conversion_price > 1.3`（標的股價超過轉換價 130%，發行人可能強制轉換） |
| 4 | 到期賣回保護 | +12 | `0 < 距賣回日天數 < 180` 且 `put_price > cb_close`（賣回價高於市價，有下檔保護） |
| 5 | 深度價內 | +10 | `underlying_close / conversion_price > 1.5`（CB 已深度價內，轉換價值遠高於面額） |
| 6 | 低於面額 | +8 | `cb_close < 100`（CB 市價低於面額，到期至少拿回 100） |

### 標的股連動訊號（2 個）

| # | 訊號名稱 | 分數 | 觸發條件 |
|---|---------|------|---------|
| 7 | 標的股強勢 | +12 | `underlying_strength > 70`（標的股技術訊號強度高） |
| 8 | 標的股弱勢 | -15 | `underlying_strength < 30`（標的股技術訊號強度低） |

`underlying_strength` 來自 `stock_technical_signals.normalized_score`。若標的股無技術訊號記錄則為 `None`，跳過此兩個訊號。

### 風險訊號（2 個，負分）

| # | 訊號名稱 | 分數 | 觸發條件 |
|---|---------|------|---------|
| 9 | 高溢價風險 | -15 | `premium_rate > 20%`（CB 市價遠高於轉換價值，套利空間為負） |
| 10 | 到期逼近 | -10 | `距到期日 < 90 天` 且 `premium_rate > 10%`（快到期但溢價仍高，收斂風險大） |

### 正規化公式

```
理論範圍：-40 ~ +92
RAW_SCORE_MIN = -40
RAW_SCORE_RANGE = 140（留緩衝）
normalized = ((raw_score - (-40)) / 140) * 100
clamp 到 [0, 100]
```

| normalized | 風險等級 |
|------------|---------|
| >= 80 | 強力套利 |
| >= 60 | 套利機會 |
| >= 40 | 觀望 |
| < 40 | 風險警示 |

基準分數：`raw_score = 0` → `normalized = 28`（無訊號觸發時的中性值）

### 資料來源與已知限制

| 資料 | 來源 | 限制 |
|------|------|------|
| CB 清單 + 發行時轉換價 | TPEX OpenAPI `bond_ISSBD5_data` | 轉換價為發行時價格，經除權息調整後不會更新 |
| CB 每日交易資料 | TPEX `cbDayQry` POST | 每次回傳一個月，僅 11 個欄位（無轉換價） |
| 標的股收盤價 | `stock_daily` 表 + TWSE/TPEX Open Data 補齊 | Open Data 僅最新一天，歷史仍依賴 `stock_daily` |
| 標的股技術強度 | `stock_technical_signals.normalized_score` | 無記錄時為 `None`，跳過強勢/弱勢訊號 |

## 五、綜合評分

API 回傳 `overall_strength`，由前端傳入的權重加權計算：

```
overall = chip_normalized * chip_weight
        + tech_normalized * tech_weight
        + fund_normalized * fund_weight
```

預設權重：`chip=0.4, technical=0.3, fundamental=0.3`

| overall | 風險等級 |
|---------|---------|
| >= 70 | 低 |
| >= 40 | 中 |
| < 40 | 高 |
